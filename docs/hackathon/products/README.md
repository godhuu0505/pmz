## 共通テンプレート（各ファイルの構成）

1. 基本情報（作品名 / チーム / 受賞 / 開催回 / リンク）
2. 社会課題（誰の・どんな痛みを対象にしたか）
3. 解決内容（何をどう解決するか・主要機能）
4. 技術スタック（GCP/モデル/フレームワーク/フロント）
5. 技術的工夫ポイント（エージェント設計・RAG・マルチモーダル等）
6. デモ / UX の見せ方
7. 多観点評価（新規性 / 実用性 / 本番品質・拡張性 / ビジネス性 / UX / 審査軸との噛み合い）
8. pmz への学び（差別化・流用できる戦術）
9. 出典 / 確度の注記
