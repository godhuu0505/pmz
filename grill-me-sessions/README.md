# grill-me-sessions

`grill-me` スキルが要件ヒアリングの状態を永続化するディレクトリです。

- 1セッション = 1ファイル: `<plan-name>.grill.md`
- 決定 (DECIDED) / 保留 (DEFERRED) / 解消 (RESOLVED) と「確定要件（ドラフト）」を記録します
- 会話をまたいで再開できます。続きをやるときは同じプラン名を指定してください
- 完了したセッションファイルは、そのまま要件定義のドラフトとして使えます

> このディレクトリはコミット対象にしても構いません（要件ドキュメントの履歴として残す場合）。
> 残したくない場合は `.gitignore` に `grill-me-sessions/*.grill.md` を追加してください。
